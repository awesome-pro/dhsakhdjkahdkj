# Sample Project

This is a sample project repository that demonstrates basic functionality.

## Overview

This project contains a simple Python application with the following features:
- A main script that prints greeting messages
- Unit tests to validate functionality
- Clean, documented code structure

## Files

- `main.py` - Main application script
- `test_main.py` - Unit tests for the main module
- `README.md` - This documentation file

## Usage

Run the main application:
```bash
python3 main.py
```

Run the tests:
```bash
python3 -m unittest test_main.py -v
```

## Requirements

- Python 3.x

## Features

- Simple hello world functionality
- Comprehensive test coverage
- Clean code structure with documentation
